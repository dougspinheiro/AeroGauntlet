# Base de Conhecimento

Diretrizes especializadas que complementam o documento mestre. São **orientação**,
não requisito validado: quando a Constituição, o documento mestre ou a medição
disserem outra coisa, eles prevalecem.

## Como usar

1. Leia a diretriz do domínio antes de projetar aquele sistema.
2. Trate cada afirmação como hipótese que precisa ser verificada no produto.
3. Se a diretriz conflitar com medição real, corrija a diretriz.
4. Não copie conclusões para o documento mestre sem reconciliar com o estado atual.
