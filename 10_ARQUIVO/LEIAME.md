# Arquivo

Guarda material substituído sem transformá-lo em fonte normativa concorrente.

## O que vai para cá

- Documentos substituídos por versão mais recente.
- Evidências que deixaram de valer (`SUPERSEDED`).
- Especificações antigas de sistemas alterados.
- Materiais de marketing obsoletos (mockups, textos, capturas antigas).
- Builds antigas de referência (somente metadados; binários grandes ficam fora).

## Regras

1. Todo item arquivado recebe cabeçalho:
   ```
   SUPERSEDED em AAAA-MM-DD por <caminho do substituto>
   Motivo: <curto>
   Não usar como fonte normativa.
   ```
2. Nada é apagado do arquivo sem decisão humana.
3. Itens não são editados depois de arquivados.
4. Documento ativo continua nos caminhos canônicos; o arquivo serve à
   rastreabilidade, não à leitura corrente.

## Estrutura

```
10_ARQUIVO/
  AAAA-MM-DD_<assunto>/
```
