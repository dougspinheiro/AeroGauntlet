# Marketing

Identidade, pesquisa e lançamento. Regra central: toda afirmação pública precisa ser
verificável no produto executável.

## Documentos

| Documento | Assunto |
|---|---|
| `IDENTIDADE_VISUAL.md` | Nome, paleta, logo, voz, tagline de trabalho |
| `POSICIONAMENTO.md` | Proposta de valor, modelo comercial, diferenciação |
| `PLANO_DE_LANCAMENTO.md` | Alpha → beta → Early Access → 1.0 |
| `ASSETS_PROMOCIONAIS.md` | Trailer, capturas, key art, ícone, descrições |
| `PESQUISA_DE_MERCADO.md` | Comparação com referências do gênero |
| `PESQUISA_DE_JOGADORES.md` | Classificação de avaliações públicas em temas |

## Regras

- Captura promocional é de gameplay real e identificada como tal; mockup nunca é
  apresentado como gameplay.
- Nenhuma promessa de funcionalidade planejada (`03_TRABALHO/02_POS_MVP/`).
- Nenhuma alegação de "48 aeronaves" enquanto o catálogo não estiver validado.
- Nada de comparação depreciativa com concorrentes.
- Publicação, orçamento e contratação de mídia são decisões humanas.
